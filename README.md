# 💻 Prabash Sandakalum – Personal Portfolio

Welcome to my personal portfolio website! 🚀

This portfolio showcases my skills, projects, education, interests, and contact information as a Computer Science undergraduate and aspiring software developer.

---

## 🌐 About the Project

This is a modern and responsive personal portfolio website designed to present my technical skills, development projects, and professional profile in a clean and user-friendly interface.

The website features a **Cyber Blue** visual theme with a **Dark Mode as the default theme**, while users can switch to Light Mode whenever they prefer.

The portfolio uses a modern **Cyber Blue** color palette.

🌙 Dark Mode
